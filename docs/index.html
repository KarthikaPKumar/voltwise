What drives the capacity-change model?

Average held-out permutation importance: increase in change-prediction error when a feature is shuffled. Correlated features and only four cells make these rankings unstable. Importance is not a causal explanation.

Where this model should not be used

These room-temperature laboratory cells have different discharge cut-offs and do not represent modern vehicle packs. The model cannot estimate driving range, calendar ageing, remaining lifetime, charging-policy effects, warranty savings or safety. It has no calibrated uncertainty interval. Real deployment requires larger, representative vehicle datasets, pack-level validation, temporal monitoring and engineering review.
